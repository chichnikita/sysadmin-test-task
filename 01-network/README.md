# Настройка сети

## Проверка текущей сетевой конфигурации

Сначала проверяем текущий IP-адрес и таблицу маршрутизации:
```
ip a
ip route
```
На данном этапе IP-адрес получен автоматически через DHCP.

![[5.png]]
## Настройка статического IP-адреса
Редактируем файл конфигурации сети
```
/etc/network/interfaces
```
Для интерфейса `enp0s3` задаём статическую конфигурацию:
```
auto enp0s3
iface enp0s3 inet static
    address 10.0.2.15/24
    gateway 10.0.2.2
    dns-nameservers 10.0.2.3
```

![[6.png]]
Проверяем, какой сетевой сервис используется:
![[7.png]]
В данном случае сеть управляется через NetworkManager.

Чтобы использовать конфигурацию из `/etc/network/interfaces`, отключаем `NetworkManager` и включаем стандартный сервис networking:
```
systemctl disable --now NetworkManager
systemctl enable --now networking
reboot
```

После перезагрузки проверяем настройки:
В ip a видим статику, а ip route правильную маршрутизацию

## Настройка VLAN

Для создания VLAN редактируем файл:
```
nano /etc/network/interfaces
```
###### Добавляем конфигурацию VLAN 10 и VLAN 20:
```
auto enp0s3.10
iface enp0s3.10 inet static
    address 10.0.10.1/24
    vlan-raw-device enp0s3

auto enp0s3.20
iface enp0s3.20 inet static
    address 10.0.20.1/24
    vlan-raw-device enp0s3
```
![[9.png]]После изменения конфигурации перезагружаем систему и проверяем созданные интерфейсы :
![[10.png]]

![[11.png]]

![[12.png]]

В выводе видно, что интерфейсы действительно являются VLAN-интерфейсами стандарта IEEE 802.1Q с идентификаторами VLAN 10 и VLAN 20.

Настроены следующие сети:

- VLAN 10 — интерфейс enp0s3.10, IP-адрес `10.0.10.1/24`
- VLAN 20 — интерфейс enp0s3.20, IP-адрес `10.0.20.1/24`

VLAN используется для логического разделения одной физической сети на несколько изолированных сетей. Например:
VLAN 10 - компьютеры сотрудников
VLAN 20 - серверы
