# Тестовое задание системного администратора
## В рамках тестового задания было выполнено следующее :
- настройка статического IP-адреса у виртуальной машины, далее VM1
- создание VLAN 10 и VLAN 20 на VM1
- настройка ssh-доступа по ключам
- настройка vpn WireGuard
- создание виртуальной машины в Proxmox VE;
- размещение документации и конфигурации в git-репозиторий

## Используемое ПО и технологии
- VirtualBox  создание тестовых виртуальных машин
- Debian  операционная VM
- OpenSSH удалённый доступ по ssh
- WireGuard  vpn-соединение между виртуальными машинами
- Proxmox VE создание и запуск виртуальной машины
- GitHub  хранение конфигураций, скриншотов и документации
